# Revhook

> 面向 Android 的 Xposed / LSPosed / Frida Hook 调试工具

<img src="logo.png" width="96" alt="Revhook">

Revhook 把脚本编写、注入调试和 AI 辅助逆向放在同一个 App 里。

## 特性

### 核心功能

- **Xposed / Frida**：编写 Hook 脚本、查看运行日志、选择注入进程
- **AI 辅助逆向**：自定义接口和提示词，辅助写脚本、搜索类、分析应用
- **APK 分析**：拆包查看类结构，可按字符串搜索混淆类

### 其他

- 从 JsxposedX 迁移数据，支持备份导入导出
- 脚本日志过滤、Logcat
- 批量导入 / 删除脚本，会话和脚本可改名
- 自定义命名规则
- 后台持续运行
- 完整日志查看、复制、导出
